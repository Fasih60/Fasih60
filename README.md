## 🏆 Featured Projects

### 🔹 [Shams Al Kananah](https://shamsalkananah.com/)
A modern, scalable full-stack e-commerce platform featuring public storefronts, an admin dashboard, and user authentication. It supports complete order and product management workflows, bilingual internationalization (English and Arabic), and is architected with a feature-based module approach to easily scale.
* **Tech Stack:** Next.js 15, React 19, TypeScript, Tailwind CSS 4, shadcn/ui, Zustand, Node.js, Express, Prisma ORM, MySQL/MariaDB
* **Status:** Live at [shamsalkananah.com](https://shamsalkananah.com/)

### 🔹 Orion
A multi-tenant SaaS platform designed for large organizations to track personnel, manage real-time statuses (like leave or postings), and organize workforce data securely. It features role-based access control, detailed audit logging, and custom grouping for targeted workforce management.
* **Tech Stack:** Flutter (Dart), provider, dio, Node.js, TypeScript, Prisma ORM, MySQL
* **Status:** Client Project
